# API-de-TS 🔌

A REST API built with **TypeScript** and **Node.js**, designed with a modular architecture for authentication, API key management and application management.

## ✨ Features

* REST API built with TypeScript
* API key management
* Application management
* Authentication middleware
* Modular controllers and services
* Structured routes
* Environment-based configuration
* Type definitions separated from business logic

## 📁 Project Structure

```text
src/
├── config/
├── controllers/
├── middlewares/
├── routes/
├── services/
├── types/
├── app.ts
└── database.ts
```

The project separates HTTP routes, controllers, business logic, middleware, database access and type definitions into dedicated modules.

## 🛠️ Technologies

* TypeScript
* Node.js
* Express
* MongoDB
* pnpm

## 🚀 Installation

Clone the repository and install the dependencies:

```bash
git clone https://github.com/tumonulo/API-de-TS.git
cd API-de-TS
pnpm install
```

Create a `.env` file in the project root with the required environment variables.

## 💻 Development

Start the development server with:

```bash
pnpm dev
```

Build the project with:

```bash
pnpm build
```

Run the production build with:

```bash
pnpm start
```
